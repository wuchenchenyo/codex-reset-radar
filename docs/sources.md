# Public sources

Last reviewed: 2026-09-13.

## Primary reset authority

Tibo ([@thsottiaux](https://x.com/thsottiaux)) is the default confirmation source for Codex hard resets. A post counts as a confirmed public event only when it clearly says usage limits were reset for a defined population (for example all paid Codex / ChatGPT Work users).

Sam Altman ([@sama](https://x.com/sama)) can confirm company-wide promotions or capacity events. Treat those as primary only when the post itself states a reset or equivalent quota restoration.

## Official accounts

- [@OpenAI](https://x.com/OpenAI)
- [@OpenAIDevs](https://x.com/OpenAIDevs)

Official posts are confirmation when they announce a reset. Product-launch copy is not a reset by itself.

## Status track

[OpenAI Status](https://status.openai.com/) is incident state, not reset state. Use it as a parallel signal. An outage may be followed by a compensation reset, but the reset still needs a primary announcement.

## Supporting product voices

- [@embirico](https://x.com/embirico) — Codex product
- [@dkundel](https://x.com/dkundel) — developer experience / rollout

These help interpret timing and scope. They do not create a confirmed record alone.

## What is not a public event

- A single account’s 5-hour or weekly window rolling over
- Unverified screenshots of 100% remaining
- Forecast language (“the resets will continue”) after a later event has already closed that window
- Banked-reset issuance unless a primary source says credits were granted broadly
